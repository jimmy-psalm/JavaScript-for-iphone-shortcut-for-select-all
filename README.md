# 詩篇全景 · 五大類 × 17 類搜尋

手機可用的詩篇分析與粵語經文朗讀。在原本 `0015 Psalm new type.html` 的 GUI／操作上，改用五大類底下的 **17 種標籤** 搜尋，不再只按單一詩篇類型（讚美詩、哀歌……）分類。

## 用哪個檔？

| 檔案 | 說明 |
| --- | --- |
| `0016 Psalm 17 type.html` | **新主程式**：17 類搜尋、小圓點亮起、經文與分析、朗讀 |
| `psalm-data v2.js` | 150 篇經文 + 舊標籤架構 + 17 類標籤（約 436 KB） |
| `0015 Psalm new type.html` | 舊版主程式（10 種單一類型），仍可開，資料檔相容 |

兩個 HTML 都要與 `psalm-data v2.js` **放在同一資料夾**。用手機 Safari／Chrome 直接開啟 HTML，或加到主畫面。

## 17 類怎麼分？

五大類沿用房志榮〈聖詠的五大類別〉（神學論集 1973）：**讚美、哀禱、感恩、王國、訓誨**。前 14 類是互斥主分類（合計 150 篇）；另 3 類可重疊，方便搜尋：

1. 讚美詩
2. 雅威為王詩
3. 錫安之歌
4. 個人哀歌
5. 群體哀歌
6. 個人信靠詩
7. 群體信靠詩
8. 懺悔詩（重疊）
9. 詛咒詩（重疊）
10. 個人感恩詩
11. 群體感恩詩
12. 君王詩
13. 智慧詩
14. 歷史詩
15. 先知勸告詩
16. 禮儀詩
17. 上行之詩（重疊，120–134）

## 操作（與舊版相同，分類改為 17 類）

1. 左上選五大類標題，或其中一個 17 類 → 全景小圓點亮起（其餘變淡）
2. 點亮起的圓點 → 右下顯示分析與經文
3. 分析面板的 17 個小圓點：本篇所屬者會亮；點選可改搜尋
4. 結構標籤、上一段／下一段、上一篇／下一篇、順序朗讀、速度／音調，全部保留
